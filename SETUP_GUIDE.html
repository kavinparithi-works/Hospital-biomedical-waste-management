What is this project?

Two minutes of context before you start

This is a complete web application for a hospital to track biomedical waste from the moment a nurse logs it to the moment a sanitation worker disposes of it — following India's Bio-Medical Waste Management Rules 2016 (the colour-coded bin system). It has three kinds of users:

🛡️ Admin

Sees the whole hospital: analytics, compliance %, charts, every record, and manages all user accounts.

🩺 Medical Staff

Doctors/nurses who log waste in a ward, pick the right bin, and assign a worker to collect it.

🚛 Sanitation Worker

Collects the waste, verifies the bag colour matches the bin, and marks it disposed.

🧩 The two programs that make it work

🖥️ Backend (API server)

Folder hospital-waste-backend. Node.js + Express. Stores everything in a MongoDB database, handles logins, and is the only part that talks to the AI photo model. Runs on port 5000.

🌐 Frontend (the website)

Folder hospital-waste-frontend. React + Vite. What you see in the browser. Talks to the backend. Runs on port 5173.

⚠️
Both must be running at the same time — so you will keep two terminal windows open. That's normal.

Fork the project on GitHub

A "fork" is your own personal copy of the repository on your GitHub account

Forking means you get a copy that you own. You can change anything, push your changes, and it will never affect the original. Here is exactly what to click:

  1. Go to github.com and sign in. (No account? Click Sign up, it's free — you'll need to confirm your email.)
  2. Open the repository page you were given — the link looks like https://github.com/SOMEONE/Hospital-biomedical-waste-management.
  3. In the top-right of the page, click the ⑂ Fork button. (If it shows a number next to it, that's just how many forks exist — click the word Fork.)
  4. A page titled "Create a new fork" opens:
    • Owner: leave it as your username.
    • Repository name: leave as Hospital-biomedical-waste-management.
    • Copy the main branch only: leave ticked.
  5. Click the green Create fork button. GitHub works for a few seconds…
  6. 🎉 You land on your copy: https://github.com/YOUR-USERNAME/Hospital-biomedical-waste-management. Notice the small grey text under the name that says "forked from …". Bookmark this page.
✅
That's the fork done. Everything from now on happens on your computer. Keep your fork's URL handy — you'll need it in the next step.

Start the database (MongoDB)

The backend needs somewhere to store users and records. Choose ONE option.
OptionGood forData kept after restart?Needs install?

B — In-memoryTrying it out, demos, laptops without Docker❌ No (resets each time)Nothing

🅰️ Option A — Docker

  1. Open Docker Desktop and wait until the whale icon / status says Engine running.
  2. In a terminal, inside the project root folder (the one containing docker-compose.yml), run:
docker compose up -d mongo
# First time it downloads MongoDB (~700 MB), then:
✔ Container biowaste-mongo  Started

MongoDB now runs silently in the background at mongodb://127.0.0.1:27017 and keeps your data in a Docker volume. It starts again automatically whenever Docker Desktop is open.

🅱️ Option B — No install, temporary database

Do nothing now. In Part 5, start the backend with npm run dev:memory instead of npm run dev. A temporary MongoDB is downloaded once (~600 MB) and started for you.

🧹
Everything resets when you stop the backend in Option B — the demo users and sample records are recreated fresh every start. Perfect for demos; use A or C for real use.

🅲 Option C — Local MongoDB

Install MongoDB Community Server (keep "Install MongoDB as a Service" ticked on Windows). The default address matches what the backend expects — nothing to change.

🔁 The big picture: life of one waste record

1. Staff logs it
status: Assigned→ 2. Worker collects
status: Collected→ 3. Worker verifies bag colour→ 4. Disposed

🗑️ The five bins (BMW Rules 2016) — the app enforces these

Bin colourWaste category in the appExamples
YellowInfectious Waste · Chemical WasteBlood-soaked cotton/gauze/dressings, soiled linen, body tissue, placenta, expired medicines, lab waste
RedContaminated RecyclableGloves, IV sets & bottles, catheters, urine bags, syringes without needle, plastic tubing

🛡️ ADMIN — what you can do

📊 Dashboard (Biomedical Waste Analytics)

Menu → Dashboard
  • Date picker (top-right) — view any day; Today jumps back; Sync refreshes; Export Audit CSV downloads the records currently shown as a spreadsheet.
  • 4 KPI cards computed from real data for the selected day:

    • Segregation Compliance — % of records where category matched the correct bin and the worker reported no mismatch. CPCB benchmark is >90%.
    • Day's Clearance — collected ÷ logged, plus the average time from logging to collection.
    • Backlog / Overdue Lots — records from previous days still not collected (red when > 0).
  • Weekly trend chart — Sunday-to-Saturday weight per bin colour for the week containing the selected date. Hover for exact kg.
  • Hazard Classification Ratio donut — share of weight per bin colour with exact kg.
  • Operational Waste Log Stream — every record for that day. Tabs: All / Pending / Completed / Cancelled. Search by record ID, room, category or staff name; filter by category. 15 per page. The 🗑 button permanently deletes a record (asks for confirmation).

⚙️ Settings & Hospital Profile

Menu → Settings

🩺 MEDICAL STAFF — what you can do

📋 Dashboard

Menu → Dashboard
  • 5 KPI cards: Records created today · Total weight today · Pending collections (with overdue count) · Collected / ready to dispose · Disposed today + today's compliance %.

➕ Add Waste Record

🤖 KMCH AI Waste Assistant (chatbot) on Add Waste Record (staff) and Dashboard (worker)

Troubleshooting

Click a problem to see the fix
❌ Backend says "Could not reach MongoDB" / "MongoDB connection error"

The database isn't running. Open Docker Desktop and run docker compose up -d mongo from the project root — or start the backend with npm run dev:memory, which needs no database.

❌ "Port 5000 is already in use"

An old backend is still running in another window. Close it (Ctrl+C), or force-stop it:

Windows PowerShell 
Get-NetTCPConnection -LocalPort 5000 | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
Mac 
lsof -ti:5000 | xargs kill -9
❌ Website shows "Cannot reach the server. Please check that the backend is running."

Terminal 1 (backend) is not running or crashed. Check localhost:5000/api/health. Restart with npm run dev inside hospital-waste-backend.

❌ "Invalid username or password"

Check: (1) you clicked the matching role card first, (2) password is Password123 with capital P, (3) the account isn't one of the intentionally deactivated ones (staff010, staff020…, worker012, worker024…).

❌ "Access denied. Account role is 'worker', not 'admin'"

You chose the wrong role card. Go back and pick the card that matches the account.

❌ "Your session has expired. Please log in again."

Normal after 12 hours, or when you restarted the backend with a different JWT_SECRET, or restarted the in-memory database. Just log in again.

❌ npm / node / git "is not recognized"

Not installed, or the terminal was opened before installing. Install from Part 1, then close and reopen the terminal. node --version must show 20 or higher.

❌ PowerShell: "running scripts is disabled on this system" 
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Answer Y, then run the npm command again.

❌ npm install fails with EACCES / permission errors (Mac)

Don't use sudo. Fix npm's folder permissions once: sudo chown -R $(whoami) ~/.npm, then run npm install again.

❌ Docker: "Cannot connect to the Docker daemon"

Docker Desktop isn't open. Open it, wait for "Engine running", retry.

❌ Chatbot photo says "Photo scanning is unavailable / not configured"

Expected if you haven't added a Gemini key. Get a free key at aistudio.google.com, put it in GEMINI_API_KEY= in hospital-waste-backend/.env, restart the backend. Text and voice work without it. Full walkthrough with screenshots-style steps: ENABLE_PHOTO_SCAN.md.

❌ Microphone button says "not supported" or does nothing

Speech recognition works in Chrome and Edge. Allow microphone access when the browser asks (🔒 icon in the address bar → Microphone → Allow).

🔄 Reset all data back to the fresh demo state Docker (Option A) 
docker compose down -v
docker compose up -d mongo

Then restart the backend — it re-creates the demo users automatically. (In-memory: just restart the backend.)

FAQ & glossary

Short answers to common questions
Do I need internet to run it?

Only for the first npm install, Docker image download, Google Fonts, and the optional photo AI. Everything else runs locally.

Can several people use it at once?

Yes — anyone on the same Wi-Fi can open http://YOUR-PC-IP:5173 if you start the frontend with npm run dev -- --host and set VITE_API_URL=http://YOUR-PC-IP:5000/api in the frontend .env.

Where is the data stored?

In MongoDB (Docker volume biowaste-mongo-data, or your local MongoDB). Nothing is sent anywhere except photos to Google when you use photo scanning with your own key.

How do I add a new language?

In hospital-waste-frontend/src/i18n/translations.js add an entry to LANGUAGES and a dictionary object. Missing keys fall back to English, so you can translate gradually.

How do I change the hospital name / colours?

Name: common.hospital, common.appName in translations.js. Colours: CSS variables at the top of src/index.css.

What is the "hospital-waste-dashboard" folder?

An older Flask (Python) prototype kept for reference. It is not used by the website and you can ignore it.
