  2. Click the Fork button (top-right) → Create fork.

3

Start the database (MongoDB)

Pick ONE of the three options — Option A is recommended

🅰️ Option A — Docker (recommended, data is saved)

Make sure Docker Desktop is open, then from the project folder:

docker compose up -d mongo

That's it — MongoDB is now running in the background at mongodb://127.0.0.1:27017. It will keep your data between restarts.

🅱️ Option B — No install, temporary database

Skip this step entirely and in Step 4 use npm run dev:memory instead of npm run dev. A throwaway MongoDB starts automatically (first run downloads ~600 MB once).

🧹
Data disappears when you stop the backend with Option B. Great for demos and testing; use Option A or C if you want records to persist.

🅲 Option C — MongoDB installed locally

Install MongoDB Community Server and make sure the service is running. Nothing else to change — the default connection string already points to it.

4

Start the backend (API server)

Terminal #1 — leave it running

4.1 — Go into the backend folder & install packages

cd hospital-waste-backend
npm install

4.2 — Create your .env settings file

Windows PowerShell 
Copy-Item .env.example .env
Mac / Linux 
cp .env.example .env

Open .env in any editor. It looks like this — the only line you must change is JWT_SECRET (type any long random text):

MONGO_URI=mongodb://127.0.0.1:27017/biowaste_db
PORT=5000
TZ=Asia/Kolkata

# Change this to any long random sentence — it signs login tokens
JWT_SECRET=my-super-secret-kmch-key-2026-change-me
JWT_EXPIRES_IN=12h

CORS_ORIGIN=

# Optional: enables photo-based waste identification in the AI assistant
# Free key: https://aistudio.google.com/app/apikey
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-2.5-flash

4.3 — Start it

If you used Option A or C (real MongoDB) 
npm run dev
If you chose Option B (no database installed) 
npm run dev:memory

You should see this — the demo users and sample records are created automatically on first start:

Connected to MongoDB at mongodb://127.0.0.1:27017/biowaste_db
Seeding 150 users (Admin, 75 Staff, 75 Workers)...
Seeded 151 new users successfully!
Sample weekly waste records seeded successfully!
Backend server is running on http://localhost:5000
🧪
Quick check: open http://localhost:5000/api/health in your browser. You should see {"status":"ok", ... "database":"connected"}.
Optional: add 6 weeks of history so the admin charts look full

Open a new terminal (keep the backend running) and run:

cd hospital-waste-backend
npm run seed:history

(Only works with a real MongoDB — Option A or C.)

Backend running on a different computer or port?

Copy .env.example to .env inside hospital-waste-frontend and set VITE_API_URL=http://THE-ADDRESS:5000/api, then restart npm run dev.

8

Troubleshooting

Click a problem to see the fix
❌ "Could not reach MongoDB" / "MongoDB connection error"

The database isn't running. Start it with docker compose up -d mongo (Option A) — or use npm run dev:memory instead, which needs no database at all.

❌ "Port 5000 is already in use"

Another backend is still running. Close the other terminal, or change PORT=5001 in the backend .env and set VITE_API_URL=http://localhost:5001/api in the frontend .env.

Windows: find & stop it 
Get-NetTCPConnection -LocalPort 5000 | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
❌ Website shows "Cannot reach the server"

The backend (Terminal 1) isn't running or crashed. Check that localhost:5000/api/health opens. Restart with npm run dev in hospital-waste-backend.

❌ "Invalid username or password"

Make sure you clicked the matching role card first (e.g. Worker Login for worker001). Password is Password123 with a capital P. Remember staff010, staff020… and worker012, worker024… are intentionally deactivated.

❌ "Your session has expired"

Normal after 12 hours, or if you restarted the backend with a different JWT_SECRET, or restarted the in-memory database. Just log in again.

❌ npm install fails or 'npm' is not recognized

Node.js isn't installed or the terminal was opened before installing. Install the LTS from nodejs.org, then close and reopen the terminal. Check with node --version (should be 20 or higher).

❌ PowerShell: "running scripts is disabled on this system" 
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Answer Y, then run the npm command again.

❌ Photo identification says "Gemini API key is not configured"

Get a free key at aistudio.google.com, put it in GEMINI_API_KEY= in the backend .env, restart the backend. Text & voice assistant work without it.

🔄 I want to reset all data back to the demo state Docker (Option A) 
docker compose down -v
docker compose up -d mongo

Then restart the backend — it re-seeds automatically. (With dev:memory, simply restart the backend.)

🔄 Get the latest updates from the original repository 
# one time: add the original repo as "upstream" (replace with the original owner's URL)
git remote add upstream https://github.com/ORIGINAL-OWNER/Hospital-biomedical-waste-management.git

# whenever you want the newest changes
git pull upstream main
git push
🛡️
Never commit secrets. The .env files are ignored by Git on purpose. Keep your JWT_SECRET, Gemini key and GitHub tokens private — if one leaks, regenerate it.
